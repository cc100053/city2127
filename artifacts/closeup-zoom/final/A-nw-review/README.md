# NW automation hub: three trials, not accepted

The requested roof logistics and immediately readable tier change remain **unmet**. The working tree restores the pre-trial F candidate for NW; the retained SE candidate is unaffected. The roof additions in the trials read as small blocks and lines, rather than recognizable logistics, at the exhibited focal view. The high tier itself is visually distinct, but the roof does not explain automation. Two-second human recognition was not tested.

- [R2](../A-nw-r2/): enlarged tracks, parcels and indicators. The camera changed during the capture, which was then interrupted: only the day images before that change are comparable; any night images are contaminated and must not be used for comparison.

R3 camera and art are not retained. [Exact R3 trial patch](trial-r3.patch.gz) includes the added state tests and allows reproduction.
- [Stable baseline performance](../A-nw-perf-before/capture.json): headless Chrome 156, 1600 × 900, ~60 fps and 950 hero / 947 focal total frame calls. These are whole-frame measurements, not isolated per-site GPU calls; no comparative trial performance claim is made.

The trial's targeted automationHub test passed after sharing the upper joints' material. The pre-trial code has been restored; no NW implementation is represented as completed. Screenshots show automatic dev meter states, not live timed transitions. Owner review should decide whether a substantially different site/camera treatment is warranted.
