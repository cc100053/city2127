## Automated checks for the current prototype

Use Node 24+. Run from the root (install only when absent/lockfile changes):

```sh
npm ci
npm ci --prefix survey
npm test
npm run build
git diff --check
```

Root pipeline tests start the real survey HTTP/WebSocket server, so survey dependencies are required. Root does not run the separate package suites. When survey changes:

```sh
cd survey
npm test
npm run build
```

When module-swap changes, from its package directory:

```sh
npm run install:app
npm test
npm run build
```

CI uses Node 24, installs/tests/builds all three packages and checks committed whitespace. Local checks gate integration; main CI must pass after integration (branch CI need not be awaited, 2026-10-06). Documentation-only pushes skip CI; a newer push cancels an in-progress run on the same branch. The Odaiba route/clearance test raycasts through `three-mesh-bvh` (test-only devDependency) with the same hits as three's brute-force raycast. CI headroom (2026-11-10, [handoff](handoffs/ci-headroom.md)): the street-car clearance sweep in `odaiba.test.ts` spent ~207 of the file's ~245 s locally (and most of the 15 min CI budget on slow runners; main run 42613769184 hit the timeout) because three's `InstancedMesh.raycast` tested every one of the street kit's ~6,700 plant instances for each of ~240k probes. The sweep now raycasts per-instance stand-in meshes (same geometry, material, name, world matrix) filed with the other solids in 8 m cells by world bounds plus reach, keeping probes, offsets and the 0.3 m clearance unchanged. A one-off comparison against the whole-scene cast on every 7th probe (20,823 probes; repeated at 3 m reach, 986 with hits) gave identical object names and distances. The file now takes ~45 s locally (root `npm test` 2 min 58 s); branch CI run 42645964933 took 9 min total with `npm test` at 7 min 21 s; the housing H2 city check (~12 s) was not the bottleneck. A configured workflow is not a passing run. [Git workflow](CONTRIBUTING.md) defines exact checks and race handling.

Documentation-only changes require local Markdown file/anchor checks, tracked-target checks, renamed-path/plain-text-reference checks, source fact checks and self-review of the complete diff. Check both working/staged diffs and `git diff --check origin/main...HEAD`. Rendering/tests/builds are not required for prose-only changes, and CI skips pushes that touch only `docs/**` or `*.md`. No source/asset change can be disguised as documentation-only.

## Evidence storage

Owner decision 2026-11-03: screenshots and round evidence are two layers.

- **Evidence** (raw captures, rounds, crops, Gemini candidates, logs): outside Git in `$CITY2127_EVIDENCE_ROOT/<task>/`, default `~/city2127-evidence/`. Every worktree on one Mac shares that absolute path, so sessions hand evidence over without pushing it. Browser runners write there through `scripts/evidence.mjs`; `CITY2127_EVIDENCE_DIR` still overrides one run. Fixed captures: `npm run capture -- [--size=WxH] [--settle=s] [--ui] <url> <task/round/name> ...` (a `?…` url goes to `$CITY2127_URL`, default `http://127.0.0.1:5173/`) reuses one headless Chrome for every pair, hides the UI, and writes a `.json` sidecar beside each image with the URL, commit, branch, dirty-tree flag, viewport and canvas diagnostics; `scripts/closeupSheet.mjs` shares its loader.
- **Records** (owner targets, review boards, the captures a document links to): committed under `artifacts/<task>/` only through `node scripts/publish-evidence.mjs <task> <image>...`, which writes JPEG q85 at ≤ 2400 px width.
- CI (`scripts/check-artifacts.sh`) fails when a push adds a PNG/video or a file over 4 MB to `artifacts/`; split or crop a larger board. Existing files are unaffected.
- On 2026-11-03, 968 tracked captures (1.19 GB) that no document, skill, source or artifact page linked to moved to the evidence folder at the same relative path ([handoff](handoffs/archive/artifacts-evidence-split.md)). Evidence exists only on the owner's Mac and its Time Machine backup; collaborators see records.
