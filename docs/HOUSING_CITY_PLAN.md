2026-10-26。產品決策：cc100053；規劃整理／實作 owner：Codex。狀態：**H0／H1 已簽收，H1b–H3 待完成**。本計劃按Claude review修訂；H0的基準／候選位置／設計矩陣／預算提案及本機檢查已由cc100053於2026-10-26在實作chat確認，見 [H0證據](../artifacts/housing-city-h0/README.md)。H1 已新增隔離 DEV 住宅靜態比較；動畫、正式問卷及展覽資料未修改。現行行為以 [EXHIBITION_SPEC](EXHIBITION_SPEC.md) 為準，實際驗證與下一步見 [任務交接](handoffs/housing-city.md)。

## 目標與範圍

延續 [能源城市計劃](ENERGY_CITY_PLAN.md#目標與範圍) 的四領域分類，處理「建築・居住」：用使用者提供的四個仮説，增加台場建築與居住形態的多樣性。新增內容與既有建築共存，延續 [CITY MASTER TASTE](ODAIBA_2127_REFERENCES/CITY_MASTER_TASTE.md) 的淡色複合材料、可見支承與接點、架空空間及台場公共生活，並保留海面、天空及重要結構留白。

本輪不改四題提案、Meter、累積規則、資料庫或live結果時序。階段編號用H0–H3，避免與居民體驗P1–P5及能源E1–E5混淆。

## 已確認方向（cc100053，2026-10-26）

1. 第一階段先做城市視覺／動態比較，正式問卷與累積規則之後決定。
2. 各仮説原則上平均發展；仮説4按下文限制暫緩，仮説1–3同輪規劃與評審。
3. 新增內容須在主鏡頭清楚可見，分布於數個區域；目的是增加多樣性，保留現有建築種類，不把全城換成新形態。
4. 新材料：以分散輕量中低層住宅＋有支承的架空生活空間為主；大型集約骨架只作少量焦點，且須與Q4集約塔分開（見H0）。
5. 植物膜：植物／苔蘚型與藻類設備型共存，分布在不同建築。
6. 可移動建築：固定骨架交換生活艙，以及少量完整小屋沿專用路徑搬遷，兩種都納入。
7. 身體自立：只保留概念，本輪不實作，不改現有居民、住宅或生活設施。

結構、外皮、更新方式可以組合在同一棟建築上，與原有建築共存；這不是四座互斥城市，H1須以至少一棟複合建築驗證。

## 原文分支取捨

原文每個仮説有A／B／C三分支。以下記錄本輪取捨，未列為「採用」的分支不是遺漏：

| 仮説 | 分支 | 本輪 | 理由 |
| --- | --- | --- | --- |
| 1 新材料 | A 少數超巨大建築集約 | 縮減為少量焦點骨架 | 全城集約會取代現有種類；且與Q4 `urbanConcentration` 的集約塔重疊 |
| | B 輕量中低層分散 | **採用（主）** | 可組裝／交換／修理，與現有塔樓／pods有別 |
| | C 生活空間離地 | **採用（主）**：柱或纜索支承 | 不做真正浮遊；地面留給公園、廣場、物流 |
| 2 植物膜 | A 全城覆蓋植物 | **刻意不採用** | 違反「保留現有種類」；綠化以形態而非數量表達 |
| | B 為植物改變建築形狀 | **採用（主）**：斜面、棚架、供水設備 | 主鏡頭距離下最易讀；只加厚外皮遠看等同換色 |
| | C 隨環境變化外觀 | 待定 | 是否可見開合未決定，H2才評估 |
| 3 可移動 | A 建築整體移動 | 縮減為少量完整小屋 | 巨型建築移動需專用基礎／接駁，超出本輪 |
| | B 骨架固定、模組交換 | **採用（主）** | 不需移動整棟建築 |
| | C 城市定期重編 | 不採用 | 需全城重排系統；原文亦建議以數年至數十年計 |
| 4 身體自立 | A／B／C | 只保留概念 | 見文末備忘 |

## 與現有project的連接

- **新材料**：延伸現有集中／分散建築種類。Q4不代表材料選擇，新材料不能當成集中程度的必然結果；集約骨架不可讀成Q4投票結果。
- **植物膜**：延伸現有綠屏、屋頂及環境設備。Q3已改為獨立能源選擇（[E4](ENERGY_CITY_PLAN.md#e4正式接入2026-10-24)），不能假設觀眾投過植物膜票。綠化須保持茂盛，未來感來自形態及邊緣，不用稀疏格狀花槽代替。
- **可移動建築**：新增有限路徑及接駁位置。現有固定slot或淡入淡出不等於建築搬遷系統；專用路徑要與 `src/mobility.ts` 的行人／車輛及 `src/skyways.ts` 共同做佔位檢查，不只在畫面上避開。
- **身體自立**：保留作未來生活方式研究；共享意願不代表同意身體改造。
- 新增位置須與能源設備（水庭／翼／環／島）、四個focal site、步道、道路、skyways、航空及船隻路徑共同核對。

### H0：位置、設計矩陣與預算

以基準城市標示候選地面、架空及外牆承載位置。本文件未指定任何已驗證座標。

每種設計列明用途、支承、公共出入、水電接駁，以及與原有建築的共存方式：

| 仮説 | 主設計（H1） | 次設計（H1b） | 必須讀到的差異 |
| --- | --- | --- | --- |
| 新材料 | 輕量分散住宅＋有支承的架空生活空間 | 少量集約骨架焦點 | 跨度、重量感、骨架與可拆接構造有別於現有塔樓／pods |
| 植物膜 | 為植物改形的建築：斜面／棚架＋苔蘚外皮 | 藻類面板與循環設備 | 外皮有厚度、承載及供水邏輯；形狀改變，不是同一材質換色 |
| 可移動 | 固定骨架＋可交換生活艙 | 完整移動小屋及專用路徑 | 可辨識固定骨架／移動部分、搬運路徑、目的地及接駁位置 |
| 複合 | 至少一棟：輕材骨架＋植物或藻類外皮＋可換艙 | — | 三類可以疊在同一建築，而非三個分開的區 |

平均發展指每個仮説各有一個主設計同輪交付；次設計在主設計通過評審後才做（H1b），以控制同輪範圍。

另須交付：

- **Q4區隔**：集約骨架與Concentration Tower（se／フジテレビ東）在位置、輪廓及材料語言上的分別；若無法分開，取消集約骨架。
- **夜間表達**：藻類面板及植物膜在夜間是自發光、反射還是暗面，影響hour 21驗收。
- **性能上限**：以H1 baseline實測為基準，訂出新增內容可用的renderer geometry／texture／draw call增量及最低FPS。參考：E5在Mac mini（Apple M6）低畫質30分鐘平均59.94 FPS、renderer 425 geometry／24 textures（[能源交接](handoffs/energy-city.md)）。上限須在H0寫成數字，不留到H3。

通過條件：仮説1–3均有可讀主設計；新增位置與原有城市關係清楚；不靠拆掉現有主要建築騰空間；基準配置、Q4區隔、夜間表達及性能上限都已寫入交接並由cc100053確認。

### H1：隔離靜態比較

在DEV入口提供同一主鏡頭、時間及基準城市的五個配置：

1. 原有城市基準。
2. 新材料單獨加入。
3. 植物膜單獨加入。
4. 可移動建築的停泊／接駁狀態。
5. 三類共存的混合配置，含H0指定的複合建築。

各類可以分開建立，但同一輪交付及比較，避免單一仮説先佔滿整座城市。以現有Three.js工廠、共享材質與instancing製作；外部素材包不在本任務範圍。

證據沿用能源E2／E3做法：固定 `hour=12|17|21` 及 `reviewTime`、原hero鏡頭（記錄OrbitControls是否鎖定，避開E5的視角漂移限制），截圖存於 `artifacts/housing-city-h1/` 並附README記錄環境；近景每類至少一張解釋用途與構造。

通過條件（由cc100053按截圖評審簽收）：

- 主鏡頭日景能指出三類新增內容各自的位置。
- 近景能解釋用途與構造。
- 混合配置仍保留原有建築種類、四個focal site可見性及海灣留白；集約骨架不被讀成Q4結果。
- 日、暮、夜三個時刻均有截圖；夜景符合H0的夜間表達。
- 實測增量在H0性能上限內；`npm test`、`npm run build`、`git diff --check` 通過。

### H2：局部動態與恢復

完成靜態構造後，才加入生活艙交換、小屋搬遷、停泊及接駁；植物膜是否開合按H0／H1結果決定。

- 以少量、有起點／終點的可重播動作比較；不建立全城重排或通用搬遷模擬。
- **時間尺度**：原文的搬遷屬數年至數十年的都市更新。動畫須明示是壓縮時間（例如可重播循環，類似E3的60秒流程），或只在配置改變時移動；不可令畫面像日常通勤。觸發方式由cc100053選定前，不視為已確認規則。

通過條件：

- 完整掃掠範圍不穿過建築、支承或 `mobility.ts`／skyways 路徑，並有Node幾何檢查。
- 靜態閱讀及reduced motion保留清楚的停泊狀態。
- 重播及重設可重現同一配置；不逐幀建立geometry或material。
- 動態開啟時仍在H0性能上限內。

此階段仍屬DEV原型，不修改正式survey流程、資料庫或live結果時序。

### H3：收斂與正式接入評估

評審三類各自及混合效果，調整數量、位置與輪廓，再決定是否進入正式城市。

正式接入須另行選定：哪些是城市固定背景、哪些由既有偏好影響、哪些需要獨立累積狀態。不能由渲染端隨機加入然後宣稱是觀眾答案造成。

**題目限制**：每位訪客固定答四題是產品契約。新增題目或替換現有題目屬改變產品方向，須cc100053另行確認，做法參照E4只替換Q3的先例（含舊答案、舊草稿及schema相容性）。

若獲指示接入，才追蹤完整鏈：問題／答案 → 權威狀態與歷史 → CityView／parser → 模型配置 → 實際前後變化證據 → 結果卡，以及Undo、reset、reconnect、舊資料與A/B恢復。

## 身體自立仮説備忘（暫不實作）

保留三條研究分支：建築需求大幅減少、文化設施繼續存在、生存自立但仍需要個人空間。

可研究的城市表達包括戶外休息地形、身體補給節點、文化創作場所及小型私密空間；全部只屬概念，未選定居民比例、身體能力、人物造型或設備。

不因此仮説刪除住宅、醫院、飲食設施，亦不把假想能力寫成已有科學可行性。
